# From Calculator to Algorithm: Supplementary Dashboard

Interactive supplementary material for an anonymous manuscript under double-blind review:

**From Calculator to Algorithm: How Literature, Discourse, and Institutions Shape Professional Trust in AI Across Surveying and Allied Professions**

The dashboard presents the data behind each of the paper's three evidence layers. The layers are read alongside each other and are never pooled into one statistic.

## How to view

Open the page at the link provided to reviewers. It is a single self-contained HTML file (`index.html`), so there is nothing to install and nothing to run. If you prefer to view it offline, download `index.html` and open it in any modern browser. Map views load background tiles online, so those need an internet connection.

## What is inside

| Layer | Evidence | Dashboard sections |
|---|---|---|
| 1. Literature | Narrative synthesis of 56 studies on AI adoption in surveying and related professions (SWiM guidance), of which 5 report comparable technology acceptance coefficients | Screening funnel, working set overview, quantitative subset, paper map with DOI links |
| 2. Community discourse | 550,051 filtered Reddit and RPLS posts coded for sentiment, theme, and stage on a five-stage professional trust curve | Theme and sentiment, AI lens and yearly trend, trust curve, LDA topics, validation (kappa) |
| 3. Institutions | Structural comparison of AI governance between RICS (United Kingdom) and the three-tier regulatory system in the United States, including the 2026 ALTA/NSPS land title survey standards | RICS versus USA comparison |

A final section reads the three layers together, followed by the reference list.

## Navigating

- Use the left menu, or the suggested reading path at the top of each page, to move between sections.
- Charts are interactive: hover for values, click map regions for the underlying papers.
- A light and dark theme switch is in the left menu.
- The page can be printed or saved as PDF from the left menu.

## Notes for reviewers

- The dashboard opens in presenter view, a clean reading view of the study results.
- All values shown are computed from the study data embedded in the file. No data is sent anywhere, and the page makes no tracking or analytics requests.
- This repository intentionally contains no author information.
